# Calculadora GUI

Calculadora com interface gráfica desenvolvida em Python e Tkinter.

## Funcionalidades

- Operações básicas: adição, subtração, multiplicação e divisão
- Expressões com mais de uma operação, respeitando a precedência
- Histórico das operações realizadas
- Validação para operações inválidas
- Tratamento de divisão por zero
- Interface com tema rosa

## Como executar

Pré-requisitos: Python 3 instalado.

Execute o seguinte comando na pasta do projeto:

```bash
python calculadora_gui.py
```

## Exemplos

- `3*2+1` retorna `7`
- `10+2*3` retorna `16`
- `20/2-3` retorna `7`

Operadores consecutivos, como `5++2`, são exibidos como `Operação inválida`.
